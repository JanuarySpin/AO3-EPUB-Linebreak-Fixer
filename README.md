# AO3 EPUB Linebreak Fixer

一个用于修复 AO3 下载的 EPUB 文件在微信读书中出现段内换行间距异常的小工具。

**无需安装、无需上传文件、支持离线使用。**

## 开发说明

本人平时习惯把自己在 AO3 上创作的作品下载为 EPUB 再导入微信读书进行审阅。结果发现段内换行在导入后会出现异常的空白间距。精心设计的排版丢失了！所以向 ChatGPT 提出了这个问题，并经过几轮尝试和测试，最终得到了现在这个小工具。

本工具由本人发现问题、提出需求并进行实际测试，代码及网页界面主要由 OpenAI 的 ChatGPT 生成。仅使用本人创作的作品进行了测试，其他作品的兼容性有待验证。

感谢 GPT 写出了这个可以分享给其他读者使用的小工具。🥰

## 问题背景

在 AO3（Archive of Our Own）中，常见的换行方式有以下两种：

**段内换行的实际效果：**

AAA  
BBB

**独立段落的实际效果：**

AAA

BBB

但在部分 AO3 导出的 EPUB 文件中，微信读书可能无法正确显示第一种结构，导致**原本应该紧贴的两行之间出现多余空白行**。如下：

AAA  
&nbsp;  
&nbsp;  
&nbsp;  
BBB

本工具旨在解决这个兼容性问题，同时保留作者有意设计的排版区别。

## 使用方法

1. 从 AO3 下载作品的 EPUB 文件。
2. 打开本工具的网页，或者下载 `index.html` 后使用浏览器打开。
3. 选择或拖入需要处理的 EPUB 文件。
4. 点击「转换并下载」。
5. 将生成的 EPUB 文件导入微信读书。

工具不会修改原始 EPUB 文件，而是生成一个修复后的新文件。

## 实现原理

工具识别 EPUB 内部的段落内换行标签 `<br/>`，并将适合转换的结构改写为使用 `<span>` 元素控制换行。

例如：

**转换前：**

```html
<p>A<br/>B</p>
```

**转换后（示意）：**

```html
<p>
  <span class="ao3-compact-line">A</span>
  <span class="ao3-compact-line">B</span>
</p>
```

同时添加对应的 CSS，使两行文字保持紧贴，而不产生普通段落的上下间距。

普通段落结构不作转换，尽可能保留原有排版。

## 隐私说明

所有 EPUB 文件均在浏览器本地处理。

- 不会将 EPUB 文件上传至服务器。
- 不会主动收集或传输小说正文。
- 可以下载 HTML 文件后离线使用。

## 适用范围与局限

- 主要针对 AO3 下载的 EPUB 文件。
- 已在微信读书中验证过段内换行修复效果。
- 不保证所有 EPUB 阅读器和所有复杂排版都能得到相同效果。
- 对于跨越多个换行位置的复杂嵌套格式，可能无法完全转换。
- 建议保留原始 EPUB 文件，以便必要时恢复。
